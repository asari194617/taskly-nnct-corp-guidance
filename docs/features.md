# 画面と利用者設定

ホームのやることの保存先と連携設定は [Taskly連携](taskly-integration.md)、操作・認証境界の検証は [テストとカバレッジ](testing.md) を参照してください。

## 名簿番号と画面構成

初回ログイン時に Ec4（電子制御工学科4年）の名簿番号を設定します。設定は Taskly アカウントごとに MySQL へ保存し、別端末でも引き継ぎます。登録できるのは取り込み済み資料に指定企業の割り当てがある番号です。「あとで」で省略でき、ヘッダーのユーザーアイコンから開くメニューや「気になる」画面から変更できます。認証アカウントから学籍を推定する処理はありません。

最初の画面は「ホーム」です。Tasklyと完了状態を共有する「やること」と、学科に関連する業種・指定ブースとの距離・気になる企業を考慮した「おすすめ」を表示します。検索・時間帯・複数の業種・気になるの絞り込みは「探す」で行います。業種はチップで複数選択し、選択した項目のいずれかに該当する企業を表示します。指定企業と気になる企業はホーム・検索・「気になる」画面・マップで区別します。会場マップでは午前・午後を切り替え、ブースから企業詳細を開いたり、企業詳細のアコーディオンで該当ブースを表示したりできます。マップを含む各ページは、デスクトップのヘッダーとモバイル下部にナビゲーションを置きます。マップはその間の領域いっぱいに広げ、検索や地図の操作パネルを重ねます。OS の外観設定に合わせてライト・ダークを切り替え、地図の紙面と文字も追従させます。ブースの選択色と配布原本は維持します。

企業一覧には正式な対象学科の情報がないため、学科の推薦理由は業種との関連を示します。近さは同じ図面・時間帯の実際の座標から求め、ブース番号の差から推測しません。指定企業と「気になる」に登録済みの企業は推薦から除き、登録済み企業の業種をほかの候補の選択に使います。おすすめから登録すると、ほかのカードの順序を保って未登録の候補を補充します。保存に失敗した場合は元の候補を戻します。

## 企業一覧と気になる

企業情報はログイン後に一括取得し、検索結果・「気になる」のカードは最初に24社を描画します。下端へ近づくと24社ずつ追加し、「もっと見る」でも追加できます。条件を変えると最初の24社へ戻り、企業詳細を開閉するときは表示済みの件数を保ちます。自動追加時には操作中のフォーカスを移しません。

マップで企業を選ぶと、大きな画面では右側、小さな画面では下側に企業情報を表示します。情報を開いたまま地図を動かしたり、別の企業を選んだりできます。ホームや検索などから開く企業詳細は、会場マップのアコーディオンと下部の「閉じる」を持つダイアログです。

「気になる」の追加・解除は通信完了前に画面へ反映します。通信に失敗した場合は対象の企業だけを元の状態へ戻し、他の企業の操作を維持します。「気になる」では企業カードを先に、指定企業をその後に表示します。解除は保存先とボタンへ反映し、そのカードは再読み込みまで残して再登録できるようにします。アプリ内の画面移動でもカードの表示を保持し、登録件数や他の画面の絞り込みは実際の登録状態を使います。再読み込み・認証の再取得・ログアウト・セッション切れで保持を解除します。

## 会場マップの操作

マップはヘッダーとモバイル下部メニューを残した領域に表示し、企業を選択しても倍率を自動で変えません。マウス・タッチのドラッグで移動し、2本指のピンチ、Ctrl/Meta キーを押したホイール、拡大縮小ボタンで倍率を変えられます。画面上のパーセント表示は省き、表示をリセットするアイコンを置きます。マップにフォーカスした状態では矢印キーで移動、`+`・`-` で拡大縮小、`0` で標準倍率へ戻ります。検索欄には検索アイコンを表示します。「絞り込み」から企業名・業種・気になる企業・指定企業を選び、表示中の企業一覧からも企業詳細を開けます。階の切り替えは右下に置き、表示中の企業一覧を開いたまま操作できます。

地図の拡大・縮小と階変更は、企業情報を開いても右下の位置を保ちます。「凡例」で選択中・指定企業・気になるの枠線を確認できます。マウスでホバー中の企業情報はカーソル付近へ表示し、画面端では地図内に収めます。タッチ操作ではホバー表示を行いません。クリックして開く企業詳細とは独立しています。

## URLとスケジュール

画面は Next.js の静的ページに分かれています。`/` が「ホーム」、`/search/` が「探す」、`/schedule/` がスケジュール、`/map/` がマップ、`/favorites/` が「気になる」、`/documents/` が配布資料の案内です。旧 `?view=` のリンクも対応するページへ正規化します。`company` は企業詳細、`focus` はマップ上の注目企業、`session` は時間帯を指定します。`q`・複数指定できる `industry`・`saved=1` は検索条件、`assigned=1` はマップの指定企業絞り込みです。名簿番号は URL に含めません。開催当日の既定の時間帯は日本時間の午前・午後に合わせ、12:00に午後へ切り替わります。URLで指定した時間帯や手動選択（「すべて」を含む）は自動では変更しません。スケジュールは実際の開始・終了時刻から「現在」と次の予定を判定し、開いたままでも更新します。開催日以外は現在の予定を示しません。再読み込み・戻る・進むや、ログイン後の画面復帰に対応します。

カードの「気になる」は追加・解除ボタンで、選択中はチェックと押下状態で区別します。企業詳細は下部の「閉じる」ボタンで閉じます。「会場マップ」を開くとその場に地図を表示し、専用マップページへのリンクも利用できます。

## 配布資料の案内

「配布資料の案内」はスケジュールから独立したページで、元資料から抽出した見出し・段落・箇条書きとPDFへのリンクを表示します。スケジュールのリンクや、ユーザーアイコンのすぐ左にある資料アイコンから開けます。マップでも同じヘッダー内に資料アイコンを置きます。案内文そのものも実行時データとして扱い、画面コードへ埋め込みません。

## 認証と資料へのアクセス

ログインの期限・更新・失効確認と、地図・PDFの一時的な閲覧権限は [本番運用の認証とデータの境界](deployment.md#認証とデータの境界) と [非公開R2の署名付きURL](private-r2.md#署名付きurlの境界) を参照してください。取得済みの情報とマップを同じ端末で参照する条件は [オフライン参照](offline.md) に記載しています。名簿番号設定やブックマークは学校の提出・出席記録を代替しません。
